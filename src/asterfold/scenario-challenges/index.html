A fictional five-image selection already includes a strong wide view. Another nearly identical wide view is being added only because it is also attractive, while a useful detail is excluded. Which choice better increases the set's distinct information under the stated selection goal?

Show the worked answer

C. Keep the strongest wide view and add the useful detail

The detail contributes information the existing wide view does not provide, while the near duplicate repeats the same role. This choice improves variety of meaning without claiming that similar photographs can never belong together for another purpose.

A single favourite becomes a universal rule

A fictional photographer prefers one centred composition during a review and concludes that every future subject should be centred. Which interpretation better reflects what this one observation supports without turning a local preference into a universal rule for all photographs or visual purposes?

Show the worked answer

B. The centred version worked for this subject and purpose

The preference establishes that one arrangement served this particular image well. It does not prove that the same placement will suit different subjects, contexts or briefs, so the learning should retain its specific conditions.

The next exercise repeats the wrong question

A fictional photographer wants to improve edge awareness but plans another session focused only on colour palettes. Which revised exercise most directly addresses the stated learning goal while remaining a small observable task during an ordinary permitted photo walk in a familiar place?

Show the worked answer

C. Inspect and compare all four edges before selecting each frame

Edge awareness concerns what enters or leaves the image boundaries. Deliberately inspecting those edges targets the stated goal, whereas colour selection or camera comparisons may be useful elsewhere but do not directly test that specific skill.
